# Customer Support Evaluation Pipeline

An automated AI-driven pipeline for evaluating and replying to customer support tickets using LLMs. The pipeline dynamically routes tickets for human review versus automated sending based on deterministic rule checks and subjective LLM quality evaluations.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Set up your environment variables:
   Copy `.env.example` to `.env` and add your valid `ANTHROPIC_API_KEY`:
   ```bash
   cp .env.example .env
   ```

## Running the Pipeline

You can run the pipeline in two modes:

**Interactive Mode**
This mode pauses at Stage 4, allowing an operator to manually override AI-decided routes via the terminal.
```bash
python -m src.pipeline
```

**Non-Interactive Mode**
This mode executes headless without operator intervention, defaulting strictly to the AI's evaluations.
```bash
python -m src.pipeline --no-interactive
```

## Running Validation

To run the automated validation script and assert that all generated artifacts conform exactly to the PRD schema:
```bash
python validate.py
```

## Project Structure

- `src/` - Contains the pipeline stages, LLM integration (`src/llm/`), and utilities (`src/utils/`).
- `outputs/` - Contains all JSON and Markdown output artifacts generated by the pipeline.
- `logs/` - Contains the `llm_calls.jsonl` execution log for all Anthropic API calls.

## Artifact Descriptions

- `outputs/normalized_tickets.json`: Validated and formatted customer support tickets from Stage 0.
- `outputs/draft_replies.json`: First-pass LLM-generated draft replies from Stage 1.
- `outputs/policy_checks.json`: Deterministic policy evaluation scores and flags from Stage 2.
- `outputs/repaired_replies.json`: Dynamically repaired drafts for tickets that failed policy checks from Stage 2b.
- `outputs/llm_review.json`: Subjective quality and risk ratings scored by the LLM from Stage 3.
- `outputs/human_overrides.json`: Operator intervention routing overrides logged in Stage 4.
- `outputs/final_decisions.json`: The final unified routing decision and artifact output mapped in Stage 5.
- `outputs/evaluation_report.md`: High-level aggregated markdown report and insights generated in Stage 6.
- `outputs/metrics.json`: Exported numerical aggregations covering pipeline pass rates and quality averages.
- `logs/llm_calls.jsonl`: Append-only chronological trace of every LLM request and hash.
